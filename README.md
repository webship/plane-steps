# @webship-js/plane-steps

Cucumber step definitions for Plane, the open-source project and work management software (Community Edition), a pack
for [webship-js](https://github.com/webship/webship-js) (Playwright and Cucumber): logging in, a project and who may
open it, its work items and one work item, its state, comments and assignees, a new work item, and its cycles.

The steps, their documentation and CI come with the first release, `2.0.0`.
